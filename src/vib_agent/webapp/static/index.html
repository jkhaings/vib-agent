Spectrum and Trend name the CSV/XLSX layout and are ignored for UFF, WAV and .MAT. Compare reads exactly two spectrum files of the same measurement point — the earlier reading first — and reports what changed. Multi-channel is spectrum-only.
Machine geometry — all optional, and this is the section that changes what we can check. A blade or vane count lets us test the blade-pass frequency; pulley sizes let us work out the belt frequency and test for a belt fault; telling us the machine is uncoupled routes an axial 1× to bent shaft instead of misalignment. Tooth, rotor-bar and pole counts have no detector yet — we record them, print them in the report, and say plainly that they are on file awaiting one. Anything left blank is reported as not provided, never guessed.
Where on the machine the sensor sat — printed with the bearing model, so the report says which bearing the geometry belongs to.
